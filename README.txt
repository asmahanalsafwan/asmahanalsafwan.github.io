ASMAHAN AL SAFWAN — ACADEMIC WEBSITE

Files
-----
index.html   The complete website. It is self-contained and does not require external CSS or JavaScript libraries.

How to preview
--------------
Double-click index.html on a computer to open it in a web browser.

How to publish
--------------
Upload index.html to any static web host or personal domain. Once it has a public URL, that URL can be entered in the Website field of Google Scholar.

Before publishing
-----------------
1. Confirm the public email address is the one you want displayed.
2. Add your Google Scholar profile URL once you have copied the exact profile link.
3. Optionally add a professional portrait later; the current design intentionally works without one.
4. Review conference/publication status before adding further entries.

Design principles
-----------------
- One-page academic profile
- Mobile responsive
- Accessible headings and navigation
- No external fonts or tracking
- Fast-loading and easy to maintain
- Print-friendly
